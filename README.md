# Python Projects

This repository contains Python projects developed throughout my Master of Science in Business Analytics and Data Science (MS BAnDS) program at Oklahoma State University, along with independent projects focused on technical skill development. Projects are developed primarily using Google Colab and Jupyter Notebook. 

## BAN 5753 – Advanced Business Analytics

This branch focuses on Python notebooks and projects developed during BAN 5753 – Advanced Business Analytics. The course covers advanced statistical modeling, machine learning, cloud computing, data engineering, business intelligence, natural language processing (NLP), and large language models (LLMs).

Coursework and hands-on exercises cover topics including:

- **Statistical Modeling & Machine Learning:** Regression, ensemble methods, classification, model evaluation, and forecasting.
- **Cloud Computing & Data Engineering:** Google Cloud Platform (GCP), BigQuery, Cloud Storage, data ingestion, and cloud-based data processing.
- **Business Intelligence & Data Visualization:** Data analysis, reporting, and dashboard development using Looker Studio.
- **Machine Learning Operations (MLOps):** Model training, management, deployment, and inference using cloud-based tools, including Azure Machine Learning.
- **Natural Language Processing (NLP):** Text preprocessing, Bag of Words, TF-IDF, Naive Bayes classification, LSTM neural networks, and pretrained GloVe word embeddings.
- **Generative AI & Large Language Models:** Transformers, transfer learning, and LLM applications.

**Note:** This branch contains selected Python notebooks rather than a complete collection of course assignments. Some hands-on coursework, particularly work completed directly in GCP and Azure, is not included in this repository.

The notebooks demonstrate practical applications of these techniques, with an emphasis on data preparation, model development, performance evaluation, and interpreting results for business decision-making.
