# Personal Projects

This branch contains independent projects, coding exercises, and technical experiments completed outside of formal academic coursework.

The primary purpose is to develop and maintain technical skills, explore new technologies, and apply concepts through hands-on practice. While Python is a primary programming language, projects may also involve SQL, cloud technologies, data engineering tools, machine learning frameworks, and other technologies.

## Areas of Focus

- **Programming & Data Analysis:** Python, SQL, data manipulation, exploratory analysis, and visualization.
- **Data Engineering:** Data pipelines, ETL/ELT processes, data transformations, and related technologies.
- **Cloud Technologies:** Exploring cloud platforms, services, and data infrastructure.
- **Statistics & Machine Learning:** Statistical analysis, predictive modeling, and model evaluation.
- **Generative AI & NLP:** Exploring large language models, natural language processing, and AI applications.
- **Technical Skill Development:** Practicing programming libraries, frameworks, and development tools through smaller exercises and experiments.

## Purpose

This branch serves as an evolving collection of personal projects and technical references. Projects vary in scope and complexity, ranging from introductory exercises and library exploration to more comprehensive applications.

Some projects are intended for portfolio development, while others are maintained primarily for learning, experimentation, and future reference.

The content will continue to evolve as I explore new technologies and expand my technical skill set.
